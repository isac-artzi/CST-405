CST-405 Compiler Design

Compiler Extension Activities

Each option is a 2-session (2 × 75 min) in-class exercise. Students pick one extension and add it to the fully-working switch-statement compiler. Click any card to open its detailed activity sheet.

Extension 01 Moderate

String Literals & Operations

Add strings as a first-class type stored in .data, an output_string built-in, and a bump-pointer heap supporting string_concat and string_equal.

Session 1: Lexer token, AST node, TYPE_STRING, syscall 4 passthrough
Session 2: Heap allocator, string_concat, string_equal
scanner.l ast.h tac.c codegen.c
Extension 02 Moderate-Heavy

Struct / Record Types

Add C-style struct definitions, dot-notation member access, contiguous stack allocation, and pass-by-pointer to functions using base+offset MIPS addressing.

Session 1: Grammar, type table with field offsets, semantic checks
Session 2: Stack layout, TAC_MEMBER_LOAD/STORE, TAC_ADDR_OF
parser.y symtab.h semantic.c codegen.c
Extension 03 Heavy

Function Pointers & Object System

Store functions as values, call them indirectly with jalr, then build a lightweight vtable dispatch system using struct fields that hold function pointers.

Session 1: fp declaration syntax, TAC_FUNC_ADDR, TAC_INDIRECT_CALL, jalr
Session 2: fp struct fields, dot-call rewriting, implicit self argument
parser.y symtab.h tac.h codegen.c
Extension 04 Light-Moderate

Inline Assembly

Add asm("...") statements that emit MIPS verbatim, then extend with %0-style operands automatically resolved to variable frame offsets.

Session 1: asm keyword, NODE_ASM_STMT, verbatim passthrough + register spill
Session 2: Operand list grammar, %N placeholder substitution
scanner.l parser.y ast.h codegen.c
Extension 05 Very Heavy

Closures & First-Class Functions

Add fun(x) -> int { ... } anonymous functions via lambda lifting, then implement variable capture using heap-allocated environment structs and fat pointers.

Session 1: Lambda syntax, lambda lifting, indirect call (no capture)
Session 2: Capture analysis, TAC_ALLOC_ENV, fat pointer calling convention
all files heap fat pointer
Extension 06 Light

Ternary Operator & Short-Circuit

Add cond ? t : f as an expression yielding a value, then fix && and || to use branch-based short-circuit evaluation with provable side-effect tests.

Session 1: QMARK/COLON tokens, precedence, NODE_TERNARY, TAC pattern
Session 2: Short-circuit AND and OR via TAC_IF_TRUE/IF_FALSE
scanner.l parser.y ast.h tac.c

Instructor Notes

All extensions build on the CST-405-switch-statements/ compiler. Students should run make and make test-switch to confirm the baseline works before starting their chosen extension.

Recommended groupings by prior experience:

  • First-time compiler students: Extension 4 (Inline Asm) or Extension 6 (Ternary)
  • Solid understanding of phases: Extension 1 (Strings) or Extension 2 (Structs)
  • Strong students or pairs: Extension 3 (Function Pointers)
  • Advanced / graduate students: Extension 5 (Closures)

Extensions 3 session 2 and Extension 5 session 2 reference Extension 2 concepts. Consider providing a struct starter patch for teams that chose Extensions 3 or 5 without doing Extension 2.
