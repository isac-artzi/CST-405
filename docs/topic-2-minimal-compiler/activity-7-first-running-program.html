Your First Running Program

Hand-write the MIPS, run it in SPIM, then make the compiler produce it.

All topics  ›  Topic 2  ›  Activity 7
Format pairs, at a laptopTime 55 minNeed SPIM or QtSPIM installed

The point

Get one program all the way to a running executable. Nothing in this course feels real until that happens.

Do this

  1. By hand first. Take three TAC instructions —
    t0 = 2 + 3
total = t0
PRINT total
    — and write the MIPS yourself. Assume total lives at 0($sp). You need li, add, sw, lw, and the two syscalls.
  2. Assemble and run YOUR hand-written version. Wrap it in a .text / .globl main / main: skeleton and run spim -file yours.s. Fix it until it prints 5.
  3. Now implement the code generator for those three TAC opcodes: TAC_ASSIGN, TAC_ADD, TAC_PRINT.
  4. Diff. Compare the compiler's output with your hand-written version. Where the compiler emitted more instructions than you did, say why — and whether the extra ones are actually necessary.
  5. Finish the phase. Add TAC_DECL and TAC_RETURN, then run every test in tests/.
The two syscalls you need
    li   $v0, 1        # print integer, value in $a0
    syscall

    li   $v0, 10       # exit
    syscall

Deliverable

Your hand-written .s file, the compiler's, a screenshot of both running in SPIM, and your answer to step 4. This is Lab Questions 9 and 10.
