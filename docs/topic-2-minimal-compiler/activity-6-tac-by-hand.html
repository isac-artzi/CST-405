Three-Address Code by Hand

Translate an AST yourself, then make the compiler agree with you.

All topics  ›  Topic 2  ›  Activity 6
Format pairsTime 50 min

The point

Translate an AST to three-address code by hand, then make the compiler agree with you. If it does not, one of you is wrong and it is worth knowing which.

Do this

  1. By hand. Write the TAC for
    int a; int b; int c;
a = 1 + 2;
b = a + a;
c = a + b + 3;
print(c);
    Use t0, t1, ... for temporaries. Number every instruction.
  2. Count your temporaries. How many did you use? How many were live at once? Those are different numbers, and the second one is what a register allocator cares about.
  3. Compare with a partner. If your instruction counts differ, you made different choices — find out what they were.
  4. Now the compiler. Implement generateTACExpr and generateTACStmt, compile that program, and read out.tac.
  5. Reconcile. Any difference between your listing and the compiler's is either your mistake or a design choice you did not know you had made. Which is it?
  6. Hand-execute the TAC. With a table of variable values, step through your listing and confirm it prints what the source program should. This is how you will debug phase 6 next week.

Deliverable

Your handwritten TAC, the compiler's out.tac, and a numbered list of the differences with an explanation for each. This is Lab Question 8.
