Full requirements and submission checklist. Due Oct 11, 2026.

Class activities

One per class meeting. Ungraded — they exist so that the assignment is not the first time you meet the idea.

Activity 1 — Derivations, Parse Trees, and Ambiguity

Derive by hand, then find two trees for one string — and fix it two different ways.

Activity 2 — First Contact with Bison

One rule at a time, and a deliberate conflict so you learn to read parser.output.

Activity 3 — Parse Tree vs AST

Draw both, count the difference, and decide what your statement list should look like.

Activity 4 — Build the Tree, Then Print It

Semantic actions, AST constructors, and a deliberate strdup bug that will save you a week.

Activity 5 — Predict the Symbol Table

Write down what the table will hold before you run anything, then grade your own error messages.

Activity 6 — Three-Address Code by Hand

Translate an AST yourself, then make the compiler agree with you.

Activity 7 — Your First Running Program

Hand-write the MIPS, run it in SPIM, then make the compiler produce it.

Activity 8 — Error Message Clinic

Score your diagnostics out of four, rewrite the worst, and swap compilers.
