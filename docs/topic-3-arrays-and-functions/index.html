Class activities

One per class meeting. Ungraded — they exist so that the assignment is not the first time you meet the idea.

Activity 1 — Precedence and Associativity Lab

Six expressions, six trees, then break the precedence table and watch what changes.

Activity 2 — Arrays Are Address Arithmetic

Do base + index×4 by hand, then make the compiler do it — for local, global and parameter arrays.

Activity 3 — Draw the Activation Record

Predict the stack frame, check it against the generated assembly, then sabotage the epilogue.

Activity 4 — Trace a Call, Including a Nested One

$a0–$a3, $v0, $ra, and why f(1, g(2)) works at all.

Activity 5 — Scope and Shadowing

Predict the output, draw the scope stack, then break exitScope on purpose.

Activity 6 — Technical Interview Rehearsal

Seven questions, ten minutes each way, at a whiteboard, out loud.
